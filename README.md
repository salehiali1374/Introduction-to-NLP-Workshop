# Introduction-to-NLP-Workshop

Welcome to the *Introduction to NLP* workshop repository! This repository contains the Jupyter notebook used in a recent workshop at the [ICDS.ai Summer Bootcamp](https://icds.ai) on Natural Language Processing (NLP), covering fundamental concepts, practical examples, and code to get started with NLP tasks.


## What the notebook covers

The notebook [`NLP.ipynb`](NLP.ipynb) walks through a classic text-mining pipeline, with explanations alongside the code:

1. **Getting a corpus:** NLTK corpora (Gutenberg, web text, chat, Brown, Reuters), loading your own corpus, and collecting tweets with Tweepy.
2. **Preprocessing:** noise removal with BeautifulSoup, tokenization, stop words, stemming and lemmatization with NLTK, spaCy and TextBlob, plus Persian examples with hazm.
3. **Linguistic analysis:** part-of-speech tagging, named entity recognition and dependency visualization with spaCy.
4. **Features:** bag of words, TF-IDF, and word embeddings (Word2Vec, pre-trained spaCy vectors).
5. **Modeling:** Naive Bayes classification, K-means clustering and rule-based sentiment analysis with NLTK.
6. **Exploration:** n-grams, frequency distributions and word clouds.

It is intended as introductory teaching material, not a production pipeline.
